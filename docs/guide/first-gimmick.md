# 最初のギミック

クリックすると鏡が出たり消えたりするスイッチを作ります。Unity でワールドのシーンを開いた状態から始めます。

## トリガーを付ける

<div class="steps">

1. スイッチにするオブジェクト（Cube など）を選びます
2. <span class="menu">Add Component → Tripwire → Tripwire Trigger</span> を付けます
3. Inspector に「いつ → 何をする」の欄と、ひな形のボタンが出ます

</div>

ひな形の「クリックで表示を切り替える」を押すと、このあとの手順をまとめて済ませられます。ここでは中身が分かるように、ひとつずつ組み立てます。

ひな形には、ほかに「管理者だけが押せるボタン」「いる人数を表示する」「10 からカウントダウン」「物を元の場所に戻す」「来た回数を数える（保存）」などがあります。どれも、押したあとにオブジェクトや文字をドラッグで入れれば動きます。

## 「いつ」を選ぶ

「＋ いつ（イベント）を追加」を押すと、イベントの一覧が開きます。左の分類から「よく使う」を選び、「クリックしたとき」を選びます。

::: tip コライダーがいります
クリックで使うには、オブジェクトにコライダーが必要です。付いていないと、カードに「コライダーを付ける」ボタンが出るので、押せば大きさを合わせて付けられます。
:::

## 「何をする」を並べる

カードの「＋ 何をするかを追加」を押し、「表示・非表示」から「オブジェクトの表示を切り替える」を選びます。「対象」に、ヒエラルキーから鏡のオブジェクトをドラッグで入れます。

<TriggerCard event="Interact"
  :actions="[{ id: 'GameObject.ToggleActive', rows: [{ p: 0, value: 'Mirror', kind: 'object' }] }]" />

## 動かす

Play を押すと、カードの内容が UdonSharp に変換され、そのまま動きます。ClientSim で、オブジェクトをクリックして確かめてください。

変換は Play とビルドの前に自動で行われます。Inspector 上部の「今すぐ反映」を押すと、その場で変換することもできます。

::: warning 赤い枠が出たら
設定に足りないところがあるカードは、赤い枠になり、カードの中に理由が出ます。Inspector の上にある状態の表示の「問題のカードを開く」を押すと、問題のあるカードだけを開けます。
:::
