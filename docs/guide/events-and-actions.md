# いつ → 何をする

Tripwire Trigger は、カードの並びです。1 枚のカードが「いつ」1 つと、そのとき「何をする」の並びを持ちます。

## カードの読み方

<TriggerCard event="OnPlayerTriggerEnter"
  :actions="[
    { id: 'GameObject.SetActive', rows: [{ p: 0, value: 'Light_A', kind: 'object' }, { p: 1, value: { ja: 'オン', en: 'On' } }] },
    { id: 'AudioSource.Play', rows: [{ p: 0, value: 'Chime', kind: 'object' }] },
  ]" />

- 左端の色の線とアイコン: イベントやアクションの分類を表し、同じ色は同じ種類
- 「いつ」のラベルの横: きっかけになる出来事で、押すと別のイベントに変えられる
- 「何をする」: 上から順に実行される

カードとアクションは、左端の ≡ をつかんで並べ替えられます。⋯ のメニューから、複製、コピーと貼り付け、メモ、削除ができます。

## イベントが持つ値

「プレイヤーが範囲に入ったとき」の「そのプレイヤー」のように、イベントには値を持つものがあります。アクションの設定で、この値を対象や値として選べます。たとえば「テレポートする」の対象を「そのプレイヤー」にすれば、動くのは入ってきた人だけです。

どのイベントが何を持つかは、[イベントの一覧](/reference/events) の「イベントの値」に書いてあります。

## かんたん と くわしく

Inspector の上の「かんたん / くわしく」で、選ぶ一覧に出る量が変わります。

- かんたん: よく使うイベントとアクションだけ
- くわしく: 物理、アバター、入力、同期データ、毎フレームなどを含む Udon のイベントすべてと、Udon での名前（`OnPlayerTriggerEnter` など）

作ったカードは、どちらにしても変わりません。

## 条件を付ける

カードの「詳細設定」を開くと、条件を足せます。そのカードのアクションが動くのは、条件を満たすときだけです。「すべて満たす / どれか 1 つ満たす」の切り替えと、条件ごとの「〜でないとき」もあります。

アクションの途中で分けたいときは、If を使います。

<TriggerCard event="Interact"
  :actions="[{ id: 'Flow.If',
    then: [{ id: 'GameObject.ToggleActive', rows: [{ p: 0, value: 'Door', kind: 'object' }] }],
    else: [{ id: 'Text.SetText', rows: [{ p: 0, value: 'Sign', kind: 'object' }, { p: 1, value: { ja: '鍵が必要です', en: 'You need the key' }, kind: 'text' }] }] }]" />

## 実行する人

カードの「詳細設定」では、アクションを誰の画面で動かすかも選べます。ふつうは「自分だけ（Local）」で、クリックした人の画面でだけ動きます。全員の画面で動かすなら「全員（All）」です。全員で同じ状態を保ちたいときは、[同期する変数](./variables) を使うほうが確実です。

## 使える人

「詳細設定」の「使える人」で、そのカードを動かせる人を絞れます。管理者だけが押せるボタンや、ワールドを作った人向けの設定パネルに使います。

| 選択肢 | 動かせる人 |
|---|---|
| 誰でも | 全員（最初の設定） |
| オーナーだけ | そのオブジェクトのオーナー |
| マスターだけ | インスタンスのマスター |
| インスタンスを作った人だけ | インスタンスを作った人 |
| リストの人だけ | プレイヤーのリストに名前がある人 |
| リスト以外の人 | プレイヤーのリストに名前がない人 |

プレイヤーのリストは、VRChat の表示名を並べたアセットです。「新しく作る」で作り、いくつものトリガーで同じリストを使えます。確かめるのは、カードを動かした人の画面で、「全員（All）」のカードでも送る前に 1 回だけです。クリックのカードがすべてリストや作った人で絞られていると、使えない人にはクリックの表示も出ません。

ネットワークで送られてきたカスタムイベントや、同期する変数の「変わったとき」は、受け取った画面の人で確かめます。絞るのは、送る側や変数を変える側のカードにしてください。

ワールドの中の確認は、改造したクライアントには破られます。大事なことには頼りきらないでください。また、公開インスタンスでは「インスタンスを作った人」が分からないという報告があります。
