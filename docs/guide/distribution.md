# 配布・販売するとき

Tripwire で作ったギミックは、Tripwire を入れていない人にも渡せます。「配布用に書き出す」で .unitypackage を作ると、受け取った人は UdonSharp（VRChat SDK）だけで使えます。

## なぜ専用の書き出しが要るか

Tripwire のカードは、Tripwire のコンポーネントに入っています。Unity のふつうの「Export Package」でそのまま渡すと、Tripwire を入れていない人の手元では、そのコンポーネントが「Missing Script」になります。動きはしますが、Missing Script の付いたプレハブは Unity が保存を受け付けないので、受け取った人は色や配置を直せません。

「配布用に書き出す」は、Tripwire のコンポーネントを外し、生成したスクリプトだけを入れます。手元のプレハブやシーンは変わりません。

## 書き出し方

1. 渡すプレハブ・シーン・フォルダを Project で選びます
2. 右クリックの「Tripwire > 配布用に書き出す…」、または Tools > Tripwire > 配布用に書き出す… を選びます
3. 書き出すもの、Tripwire を外すもの、受け取る人が入れておくパッケージを確かめて、「書き出す…」を押します

書き出す前に、トリガーが反映済みかを確かめます。反映されていないトリガーや、保存していないシーンがあるときは、直し方が出て書き出せません。開いていないシーンは、反映済みかを確かめられないので、一度開いてから書き出すと確実です。

## 受け取った人の手元

- ギミックは、そのまま動きます。必要なのは VRChat SDK（Worlds）です
- 色・大きさ・配置などは、ふつうのプレハブとして直せます
- カードとしては直せません

## カードごと渡す

書き出しの窓で「カードを残す」をオンにすると、Tripwire のコンポーネントを付けたまま書き出します。受け取る人は Tripwire を VCC から入れておく必要があり、カードとして中身を見たり直したりできます。Tripwire を使っている人向けに、両方を用意して渡すこともできます。その場合は、同じプロジェクトにはどちらか一方だけを入れてもらってください。

TextMesh Pro を使っているときは、その基本ファイル（TMP Essential Resources）も書き出しには含めません。受け取った人のプロジェクトに入っていなければ、Unity が取り込むかを聞いてきます。
