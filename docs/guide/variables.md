# 変数

変数は、トリガーが覚えておく値です。扉が開いているか、何回押されたか、今のスコアはいくつか、といったことを持たせます。

## 変数を作る

「変数」の欄の「＋ 変数」を押すと、変数が 1 つ増えます。名前を付けて、種類を選びます。

| 種類 | 持つもの | 例 |
|---|---|---|
| オン/オフ | オンかオフ | 扉が開いている、ライトがついている |
| 整数 | 整数 | 回数、点数 |
| 小数 | 小数 | 時間、音量 |
| 文字 | 文字 | 名前、メッセージ |
| オブジェクト | シーンのオブジェクト 1 つ | 動かす対象 |
| オブジェクトのリスト | オブジェクトをいくつも | まとめて操作するライト |
| プレイヤー | プレイヤー 1 人 | 最後に押した人 |

ほかの種類は、「くわしく」にすると選べます。

## 同期しない・同期する・一時的

最初の値の横で、同期するかどうかを選びます。一時的にもできます。

- 同期しない: プレイヤーごとに別の値を持ち、変えるまでその値のまま
- 同期する: 全員に同じ値が届き、あとから来た人にもそのときの値が届く
- 一時的: イベントが動くたびに最初の値から始まり、ほかのトリガーからは見えない

同期のしくみと使い分けは、[全員で同じ状態にする](./sync) にまとめています。

## 文字に値を入れる

「テキストを変える」や「ログを出す」の文字に `{スコア}` のように変数の名前を書くと、その変数の今の値に置き換わります。`スコア: {スコア}点` と書けば、看板に「スコア: 12点」と出せます。
