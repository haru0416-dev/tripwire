# If・ループ・タイマー

アクションは上から順に動きます。途中で分けたり、くり返したり、時間をおいて動かしたりするときは、「If・ループ・タイマー」の分類にあるアクションを使います。

## If で分ける

If は、条件に合うとき（Then）と合わないとき（Else）で、別のアクションを動かします。Else の中に If を入れると、Else If になります。

条件には変数を使います。数の変数なら大小を比べられ、条件を何個も並べて「すべて満たす / どれか 1 つ満たす」も選べます。カード全体に条件を付けるときに使うのは、If ではなく、カードの詳細設定の条件です。

## ループ

| アクション | くり返し方 |
|---|---|
| Repeat | 決めた回数だけ |
| For Each | リストの変数の中身を 1 つずつ |
| While | 条件を満たしている間 |

For Each は、オブジェクトのリストをまとめて操作するときに使います。中身を入れる変数を対象にしたアクションを Do に並べると、リストの全部に同じことをします。

::: warning While は終わるように
While の中で条件の変数を変えないと、ループが終わらず、そのトリガーが動かなくなります。
:::

ループの中では、Break（ループをやめる）と Continue（次の回へ進む）が使えます。Return は、そのイベントの残りのアクションをすべて飛ばします。

## タイマー

「タイマー（一定時間ごと）」のイベントは、決めた秒数ごとに動きます。

- 間隔: 秒数で、「ランダム」にすると最小と最大の間で毎回変わる
- 実行: 「くり返す」か「一度だけ」
- 最初から動かす: オフにすると、「タイマーを始める」アクションで始めるまで動かない

タイマーには名前を付け、「タイマーを始める」「タイマーを止める」でその名前を選びます。オブジェクトを非表示にしてもタイマーは動き続けます。止めたいときは、「オブジェクトが無効になったとき」（くわしくモードの「上級」）に「タイマーを止める」を置いてください。

## 遅らせる

カードの詳細設定の「遅らせる」で、イベントが起きてから何秒か後にアクションを動かせます。名前を付けたイベントを何秒か後に呼ぶ「何秒か後にカスタムイベントを呼ぶ」もあります。
