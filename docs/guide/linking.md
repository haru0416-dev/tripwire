# ほかのトリガーやスクリプト

ギミックが大きくなると、1 つのトリガーには収まらなくなります。トリガーどうしで呼び合ったり、値を渡したりできます。

## カスタムイベントで呼ぶ

「カスタムイベント」は、名前を付けたイベントです。ほかのトリガーから「カスタムイベントを呼ぶ」で、その名前を指定して動かせます。

「何秒か後にカスタムイベントを呼ぶ」を使うと、何秒か後に呼べます。カスタムイベントは、UdonSharp のスクリプトから `SendCustomEvent` で呼ぶこともできます。

## ほかのトリガーの変数

「ほかのトリガーの変数を変える」と「ほかのトリガーの変数を読む」で、別のトリガーの変数を扱えます。変えたときは、相手のトリガーの同期や「変数が変わったとき」もふつうに動きます。値を渡して呼びたいときは、変数を変えてからカスタムイベントを呼ぶ順にしてください。

## ほかのスクリプトを使う

「連携」の「ほかのスクリプトを使う」で、シーンにある UdonSharp スクリプトの関数を呼んだり、値を変えたりできます。対象にスクリプトの付いたオブジェクトを入れると、「使うもの」にそのスクリプトで使えるものが並びます。

## ほかのスクリプトからの通知を受ける

「ほかのスクリプトから通知されたとき」のイベントは、動画プレイヤーやペンなどのスクリプトが送る通知を受け取ります。「通知元」にスクリプトの付いたオブジェクトを入れ、「何が起きたとき」を選びます。通知を受け取るための登録は、ワールドが始まったときに Tripwire が済ませるので、自分で書く必要はありません。

ProTV、VizVid、USharpVideo、VideoTXL は、通知と操作の一覧を Tripwire が知っています。ほかのスクリプトは「自分で設定する…」で、届く名前と登録の方法を選びます。詳しくは [動画プレイヤー](./video-players) を見てください。

## Udon の機能を直接呼ぶ

一覧にない操作は、くわしくモードの「上級」にある「Udon の機能を呼ぶ（Udon API）」で呼べます。Udon から使えるメソッドとプロパティを検索して選びます。
