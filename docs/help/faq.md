# よくある質問

## 変換したスクリプトはどこにありますか

`Assets/TripwireGenerated` にあります。このフォルダは消さずに、.meta ファイルごとバージョン管理に入れてください。シーンのコンポーネントはこのファイルを指していて、作り直したファイルはシーンから見ると別のものになります。中身はふつうの UdonSharp なので、開いて読むこともできます。Inspector の「コード」ボタンで、そのトリガーのスクリプトを開けます。

## ワールドに来る人に何か入れてもらう必要はありますか

ありません。変換したスクリプトはふつうの UdonSharp で、VRChat に Tripwire 専用のしくみは要りません。

## 表示を英語にできますか

Inspector の上の ⋮ のメニューの「言語」で、日本語と英語を切り替えられます。作ったカードの中身は変わりません。

## 選ぶ一覧に目当てのイベントがありません

Inspector の上で「くわしく」にすると、物理、アバター、入力、同期データ、毎フレームなどのイベントも選べます。それでもないときは、[イベントの一覧](/reference/events) で名前を検索してください。

## ほかのワールドのギミックや、配布されているスクリプトと組み合わせられますか

UdonSharp のスクリプトなら、「ほかのスクリプトを使う」で関数を呼べます。スクリプトからの通知を受けるときは、「ほかのスクリプトから通知されたとき」を使います。[ほかのトリガーやスクリプト](/guide/linking) を見てください。

## VRChat の中で動きがおかしいときは

Unity の ClientSim で同じ動きになるかを確かめてください。ClientSim では動くのに VRChat で動かないときは、同期まわりのことが多いです。[全員で同じ状態にする](/guide/sync) を見直してください。それでも直らないときは、Issue で教えてください。

## 押しても何も起きません

Play 中にカードを見ると、最後に動いた時刻か、条件で止まった理由が出ます。どのイベントが動いたかは「実行の記録」でも見られます。[Play で試す](/guide/testing) を見てください。

## 作ったギミックを販売・配布できますか

できます。Tripwire を入れていない人に渡すときは、「配布用に書き出す」を使ってください。そのまま渡すと、相手の手元で Tripwire のコンポーネントが Missing Script になります。[配布・販売するとき](/guide/distribution) を見てください。
