# 用語集

説明書と Tripwire の画面に出てくる言葉です。

| 言葉 | 意味 |
|---|---|
| トリガー | オブジェクトに付ける Tripwire Trigger のこと。カードを並べてギミックを作る |
| カード | 「いつ」1 つと「何をする」の並びの組 |
| イベント（いつ） | きっかけになる出来事。クリック、範囲に入った、など |
| アクション（何をする） | イベントが起きたときに動かすこと |
| 変数 | トリガーが覚えておく値 |
| 同期 | 値を全員の画面にそろえること |
| オーナー | 同期する値を書き換える役のプレイヤー。値を変えた人が Tripwire によって自動でオーナーになる |
| 自分だけ（Local） | アクションを、イベントが起きた人の画面でだけ動かす。ほかのツールでは Local と呼ぶこともある |
| 全員（All） | アクションを、その場にいる全員の画面で動かす。あとから来た人には届かない |
| オーナーだけ（Owner） | アクションを、オーナーの画面でだけ動かす |
| あとから来た人 | 変数が変わったあとにインスタンスに入ってきたプレイヤー。同期する変数なら今の値が届く |
| Udon | VRChat のワールドでギミックを動かすしくみ |
| UdonSharp | C# で Udon のプログラムを書くためのツール。Tripwire は UdonSharp のスクリプトを作る |
| ClientSim | Unity の中で VRChat の動きを試せるツール。Play を押すと動く |
| 反映 | カードを UdonSharp に変換して、オブジェクトに付けること。Play とビルドの前に自動で行われる |
| かんたん / くわしく | 選ぶ一覧に出る量の切り替え |
