# エラーと注意

設定に問題があるカードは、枠の色と、カードの中のメッセージで知らせます。

- 赤い枠（エラー）: このままでは変換できず、直すまでトリガーは反映されない
- オレンジの枠（注意）: 変換はできるが、思ったとおりに動かないおそれがある

Inspector の上にある状態の表示に、問題の数が出ます。「問題のカードを開く」を押すと、問題のあるカードだけを開き、ほかをたたみます。たたんだカードでも、見出しに出る数字付きの赤やオレンジのアイコンにカーソルを乗せると、理由が読めます。シーンにあるトリガー全部の状態を見るには、見出しの右の一覧ボタン（トリガー一覧）が便利です。

## よく出るもの

| メッセージ | 直し方 |
|---|---|
| 対象が入っていないので、何も起きません。 | 「対象」にオブジェクトをドラッグで入れる |
| クリックで使うには、このオブジェクトにコライダーが必要です。 | カードの「コライダーを付ける」を押す |
| このイベントには範囲（Is Trigger をオンにしたコライダー）が必要です。 | カードの「範囲を付ける」を押す |
| 変数を選んでください。 | アクションの「変数」で変数を選ぶ。先に「＋ 変数」で作っておく |
| 「全員（All）」で同期した変数を変えると、全員が同時にオーナーになろうとして… | カードの詳細設定を「自分だけ（Local）」に戻す。値はもともと全員に届く |
| オブジェクトやプレイヤーは同期できません。 | 見分ける番号の変数を同期して、番号から選ぶ |
| 「カスタムイベント」で同じ名前を使っています。 | どちらかの「呼ばれる名前」を変える |
| このトリガーのタイマーを選んでください。 | タイマーのイベントに名前を付け、その名前を選ぶ |
| 「}」で閉じていない「{」があります。 | 文字として `{` を書くときは、2 つ重ねて書く |

## 「自分だけ（Local）」にしてください、と出たとき

毎フレームのイベント、タイマー、変数が変わったときなどは、もともと全員の画面でそれぞれ動きます。これを「全員（All）」にすると、同じ処理が人数分くり返されたり、ネットワークに送る量が増えすぎたりします。注意が出たら、カードの詳細設定を「自分だけ（Local）」に戻してください。
