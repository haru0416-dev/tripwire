VRChat's docs describe it as happening on your screen when you respawn by clicking Respawn in your menu. Another player's respawn doesn't run it on your screen, so keep **Whose** on **Me**.

The docs don't say whether it happens when a player respawns after falling out of the world.

To let others see that someone respawned, change a synced variable and react with On Variable Changed ([The same state for everyone](/en/guide/sync)).

Official docs: [Event Nodes (VRChat)](https://creators.vrchat.com/worlds/udon/graph/event-nodes/)
