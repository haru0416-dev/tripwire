Starts emitting. Use it for particles with Play On Awake off, to show them on a click or when someone walks in.

If it is already playing, nothing changes. A paused system carries on where it was; a stopped one starts over from time 0, with its Start Delay. Child particle systems start too.

It shows only on the screen where the action runs. To show everyone present, set the card's Advanced setting to **Everyone's screen**.

Official docs: [ParticleSystem.Play (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/ParticleSystem.Play.html)
