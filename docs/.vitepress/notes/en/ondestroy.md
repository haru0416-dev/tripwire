Happens when this object is destroyed, and also when the scene ends. It doesn't happen for an object that has never been active.

Tripwire has no action that destroys objects. To just hide one, turn it off with **Set Active** and react with OnDisable ([OnDisable](/en/reference/events/ondisable)).

Official docs: [MonoBehaviour.OnDestroy (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnDestroy.html)
