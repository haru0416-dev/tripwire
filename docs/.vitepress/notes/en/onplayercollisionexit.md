Happens when a player's capsule that was touching this object's collider moves off it. **Whose** picks which players count.

Like On Player Collision Enter, it is meant for moving things that hit a player, and isn't called when a player walks into a stationary object ([On Player Collision Enter](/en/reference/events/onplayercollisionenter)).

Official docs: [Player Collisions (VRChat)](https://creators.vrchat.com/worlds/udon/players/player-collisions/), [Event Nodes (VRChat)](https://creators.vrchat.com/worlds/udon/graph/event-nodes/)
