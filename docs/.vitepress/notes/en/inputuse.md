Happens when you press or release Use: left click on desktop, usually the trigger on controllers. To react to clicking an object, use Interact instead.

handType in **Input details** tells which hand's button it was; the mouse counts as RIGHT and the keyboard as LEFT. Acting only on press, and what happens with menus open, work as in [Input Jump](/en/reference/events/inputjump).

Official docs: [Input Events (VRChat)](https://creators.vrchat.com/worlds/udon/input-events/)
