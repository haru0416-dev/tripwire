Happens when your left/right movement input changes: A and D on desktop, usually the left stick left and right on controllers.

**How far** typically ranges from -1 to 1. With an analog stick it fires for each change, from 0 to 0.1, then 0.2 and so on. Desktop gives whole numbers only: -1, 0, 1. To use the value, put it into a Number variable with **Set Variable**.

Official docs: [Input Events (VRChat)](https://creators.vrchat.com/worlds/udon/input-events/)
