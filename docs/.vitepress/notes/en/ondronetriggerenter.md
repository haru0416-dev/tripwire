Happens when a player's drone (the VRChat+ camera drone) enters this object's area. **The drone** tells which drone it is.

To find who owns it, use **Call Udon API** with GetPlayer on this value. Store the result in a Player variable to use it as a target in other actions.

Official docs: [Drone API (VRChat)](https://creators.vrchat.com/worlds/udon/players/drones/), [Getting Drones (VRChat)](https://creators.vrchat.com/worlds/udon/players/drones/getting-drones/)
