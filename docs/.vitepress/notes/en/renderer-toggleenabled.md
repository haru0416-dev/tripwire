Flips renderers: shown ones are hidden and the other way round. Colliders and the object's other components keep working. To set a definite state, use [Set Renderer Enabled](/en/reference/actions/renderer-setenabled).

It flips them only on the screen where the action runs. To hide the whole object, use [Toggle Active](/en/reference/actions/gameobject-toggleactive).

Official docs: [Renderer.enabled (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Renderer-enabled.html)
