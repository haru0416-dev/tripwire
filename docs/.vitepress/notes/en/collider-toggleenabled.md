Flips colliders: enabled ones become disabled and the other way round. The look stays, so it suits walls you can walk through now and then, or buttons that can't be pressed for a while. To set a definite state, use [Set Collider Enabled](/en/reference/actions/collider-setenabled).

It flips them only on the screen where the action runs. Disabling an area (an Is Trigger collider) also stops that area's events.

Official docs: [Collider.enabled (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Collider-enabled.html)
