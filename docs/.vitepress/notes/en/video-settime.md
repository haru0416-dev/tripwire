**Seconds** is the time from the start of the video. It can be a number variable or a value the event brings, so the value of UI Slider Moved can scrub the video.

The position changes only on the screen where the action runs; other players stay where they were. For everyone to watch the same scene, use a player with its own sync, such as ProTV ([Video players](/en/guide/video-players)).

Official docs: [Video Players (VRChat)](https://creators.vrchat.com/worlds/udon/video-players/)
