Loads a URL without starting playback. When loading finishes, [On Video Ready](/en/reference/events/onvideoready) happens on triggers on the video player's object; run **Play Video** there to start once it's ready.

Loading counts toward the limit of one new URL every 5 seconds per player. What **URL** takes, which sites play and how to test in the editor are the same as for [Play Video URL](/en/reference/actions/video-playurl). Only the video player on the screen where the action runs loads it.

Official docs: [Video Players (VRChat)](https://creators.vrchat.com/worlds/udon/video-players/)
