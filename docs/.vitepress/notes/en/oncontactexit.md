Happens when a Contact Sender stops touching a VRC Contact Receiver. As with [On Contact Enter](/en/reference/events/oncontactenter), put the Tripwire Trigger on the Receiver's object.

**The contact** holds the Sender (contactSender) and the shared tags (matchingTags), but no position or speed. Check that contactSender's isValid is on before using it.

Official docs: [Contacts (VRChat)](https://creators.vrchat.com/common-components/contacts/)
