A 2D physics event: it happens when a Collider 2D that was inside the 2D area leaves it. **What left** is that Collider 2D. The setup is the same as [On Trigger Enter 2D](/en/reference/events/ontriggerenter2d).

Official docs: [OnTriggerExit2D (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnTriggerExit2D.html)
