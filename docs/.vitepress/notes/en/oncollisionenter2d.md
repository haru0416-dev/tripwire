A 2D physics event: it happens when another Collider 2D hits this object's Collider 2D. **What hit it** is a Collision2D with data about the collision. It isn't for regular 3D colliders or players.

For 3D collisions, see [On Collision Enter](/en/reference/events/oncollisionenter).

Official docs: [OnCollisionEnter2D (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnCollisionEnter2D.html)
