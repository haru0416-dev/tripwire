Makes the player on whose screen the action runs let go of the target pickups. Use it to make players put things down when they walk into a place where the item shouldn't go. From an area, set the card's **Who enters** to **Me**.

A pickup with Auto Hold on stays in the hand until the player grabs again or uses the drop action. This action lets go without waiting for that.

Official docs: [VRC Pickup (VRChat)](https://creators.vrchat.com/worlds/components/vrc_pickup/)
