Happens when this object becomes inactive. It also happens when the object is destroyed, so it suits cleanup.

**Set Active** turning the object off causes it, only on the screens where that action ran. To keep everyone in step, switch it with a synced variable ([The same state for everyone](/en/guide/sync)).

Keep the card's advanced setting at **Only my screen**; anything else runs the actions once per player each time.

Official docs: [MonoBehaviour.OnDisable (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnDisable.html)
