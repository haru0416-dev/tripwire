Turns only the visuals (renderers) on or off. The object keeps running, so its collisions and triggers still work while invisible.

It changes only on the screen where the action runs. To keep everyone in step, react to a synced variable with On Variable Changed and run this action there ([The same state for everyone](/en/guide/sync)).

Official docs: [Renderer.enabled (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Renderer-enabled.html)
