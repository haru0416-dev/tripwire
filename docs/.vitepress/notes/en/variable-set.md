**Value** can be fixed, another variable, or a value the event brings. Set into a synced variable, the value reaches everyone, and whoever sets it becomes the variable's owner automatically.

Setting the same value again isn't a change: a synced variable doesn't send it, and On Variable Changed doesn't run.

Players who join later get the last value of a synced variable. Keep a card that sets a synced variable on **Only my screen** in its Advanced settings. With **Everyone's screen**, every player tries to become the owner at once and ends up with a different value ([The same state for everyone](/en/guide/sync)).

Official docs: [Network Variables (VRChat)](https://creators.vrchat.com/worlds/udon/networking/variables/)
