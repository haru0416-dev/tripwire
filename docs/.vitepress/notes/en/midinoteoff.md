Happens when a MIDI Note Off arrives, usually when a key or pad is released. The VRC Midi Listener and VRC Midi Player setup is as in [MIDI Note On](/en/reference/events/midinoteon).

**Velocity** is typically 0 here, though some devices send other values. **Channel** is 0-15 and the note number 0-127.

Official docs: [Midi in Udon (VRChat)](https://creators.vrchat.com/worlds/udon/midi/)
