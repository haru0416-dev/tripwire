A 2D physics event: it keeps happening while another Collider 2D touches this one. **What touches it** is a Collision2D. It isn't sent while the Rigidbody is asleep ([On Collision Enter 2D](/en/reference/events/oncollisionenter2d)).

Official docs: [OnCollisionStay2D (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnCollisionStay2D.html)
