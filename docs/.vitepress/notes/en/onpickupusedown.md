Happens on your screen when you press Use while holding the pickup. It suits things you operate in your hand: firing a gun, switching on a flashlight.

VRChat's docs say that on desktop this needs Auto Hold on the VRC Pickup. It may work when you test in VR and still never happen for desktop players. The hint shown while holding it is the VRC Pickup's Use Text, which also needs Auto Hold.

To show the result to others, change a synced variable and react with On Variable Changed. For a sound that only players present need to hear, **Everyone's screen** in the advanced settings is enough ([The same state for everyone](/en/guide/sync)).

Official docs: [Event Nodes (VRChat)](https://creators.vrchat.com/worlds/udon/graph/event-nodes/), [VRC Pickup (VRChat)](https://creators.vrchat.com/worlds/components/vrc_pickup/)
