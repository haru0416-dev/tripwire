A 2D physics event: it keeps happening while another Collider 2D is inside the 2D area. **What is inside** is that Collider 2D. The setup is the same as [On Trigger Enter 2D](/en/reference/events/ontriggerenter2d).

Official docs: [OnTriggerStay2D (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnTriggerStay2D.html)
