Plays the AudioSource's clip from the start; running it again while playing starts over. Set the clip in the AudioSource's Inspector.

To layer the same sound, use **Play Sound Once**.

It plays only on the screen where the action runs. To let everyone present hear it once, set the card's Advanced setting to **Everyone's screen**. For a lasting sound like background music, react to a synced variable with On Variable Changed and play or stop it there ([The same state for everyone](/en/guide/sync)).

Official docs: [AudioSource.Play (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AudioSource.Play.html)
