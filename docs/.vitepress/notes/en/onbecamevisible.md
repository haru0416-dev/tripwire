Happens when this object's renderer becomes visible to any camera. The message goes to scripts on the renderer's object, so put the trigger on the same object as the renderer.

It suits work that is only needed while the object is seen, paused while it is not. The opposite is On Became Invisible ([On Became Invisible](/en/reference/events/onbecameinvisible)). In the editor, Scene view cameras count too.

Official docs: [MonoBehaviour.OnBecameVisible (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnBecameVisible.html)
