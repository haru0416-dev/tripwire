A 2D physics event: it happens when another Collider 2D stops touching this object's Collider 2D. **What left it** is a Collision2D ([On Collision Enter 2D](/en/reference/events/oncollisionenter2d)).

Official docs: [OnCollisionExit2D (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnCollisionExit2D.html)
