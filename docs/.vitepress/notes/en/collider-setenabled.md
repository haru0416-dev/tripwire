Turns only colliders on or off: the object stays visible but can't be clicked, or can be walked through.

A disabled collider no longer collides with other colliders. The change happens only on the screen where the action runs. To keep everyone in step, react to a synced variable with On Variable Changed and run this action there ([The same state for everyone](/en/guide/sync)).

Official docs: [Collider.enabled (Unity)](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Collider-enabled.html)
