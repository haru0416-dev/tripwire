「値」には、決まった値のほか、別の変数やイベントの値も選べます。同期する変数に入れると、その値は全員に届きます。そのとき、入れた人が自動でその変数のオーナーになるので、オーナーを気にする必要はありません。

同じ値を入れ直しても、変化にはなりません。同期する変数でも送られず、「変数が変わったとき」も起きません。

同期する変数は、あとから来た人にも最後の値が届きます。同期する変数を変えるカードは、詳細設定を「自分だけ（Local）」のままにしてください。「全員（All）」にすると、全員が同時にオーナーになろうとして、値が人によって食い違います（[全員で同じ状態にする](/guide/sync)）。
