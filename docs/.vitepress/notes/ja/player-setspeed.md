このアクションが動いた画面のプレイヤー自身の、歩く・走る・横歩きの速さとジャンプの強さを変えます。最初の値のうち、歩く 2・走る 4・横歩き 2 は VRChat の標準の値で、ジャンプの 3 は VRCWorld プレハブに入っている値です。ジャンプの強さを 0 にすると、ジャンプできなくなります。

ワールド全体の速さを変えたいときは、「開始したとき」に置くと、入ってきた全員の画面でそれぞれ動きます。

VRChat の説明では、歩く速さと横歩きの速さは 0〜5 くらい、走る速さとジャンプの強さは 0〜10 くらいが使いやすい範囲です。走る速さは、歩く速さより大きくします。横歩きは走っても速くならないので、歩く速さと同じにするのがおすすめです。

変わるのは自分の速さだけで、ほかの人の速さは変えられません。

公式の説明: [Player Forces（VRChat）](https://creators.vrchat.com/worlds/udon/players/player-forces/)
