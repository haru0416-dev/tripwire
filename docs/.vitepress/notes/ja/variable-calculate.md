「変数」で結果を入れる変数を選び、「A」と「B」に変数か値を入れて、「計算」で `+ − × ÷ %` のどれかを選びます。A と B の欄の型は、選んだ変数の型に合わせて変わります。

計算できるのは、数（整数・小数）、位置（Vector2・Vector3）、色、文字の変数です。位置と色は `+ −` で同じ型どうしを計算し、`× ÷` では数を掛けたり割ったりします。たとえば位置に (0, 1, 0) を足すと 1 m 上になり、色に 0.5 を掛けると暗くなります。文字にできるのは、`+` でつなげることだけです。`%` は割った余りで、数にだけ使えます。

整数を 0 で割ると、Udon ではエラーになってトリガー全体が止まります。そのため、割る数が 0 のときの結果は 0 です。B に 0 を直接書いたときは、反映する前にエラーになります。

同期する変数に入れると、ほかの「変数を変える」と同じく、値が全員に届いて「変数が変わったとき」も動きます。1 回足すだけなら「変数に足す」でも同じことができます。
