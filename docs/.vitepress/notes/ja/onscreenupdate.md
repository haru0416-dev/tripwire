モバイル端末の人が、ワールドに入ったときと、端末の向きを変えたときに起きます。起きるのはその人の画面だけです。

「画面の情報」の type は何が起きたかで、今は OrientationChanged だけです。orientation は端末の向きで、Landscape（横）か Portrait（縦）です。resolution には画面の解像度が Vector2 で入ります。

縦向きと横向きで UI の配置を変えるときに使います。

公式の説明: [Event Nodes（VRChat）](https://creators.vrchat.com/worlds/udon/graph/event-nodes/)
