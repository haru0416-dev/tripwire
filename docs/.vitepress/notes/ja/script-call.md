「対象」に UdonSharp スクリプトの付いたオブジェクトを入れると、「使うもの」にそのスクリプトの public な関数、フィールド、プロパティが並びます。関数を呼ぶほか、値を変えたり、値を読んで「結果を入れる変数」に入れたりもできます。U# スクリプトがいくつも付いているときは、「スクリプト」でどれを使うか選んでください。

ProTV、VizVid、USharpVideo、VideoTXL では、「URL の動画を再生」のようなよく使う操作が一覧の先頭に出ます。操作によっては、先にオーナーになるアクションもいっしょに入ります。ほかの項目は「すべての項目」の中です。

アセンブリ定義の Auto Referenced がオフになっているスクリプトは使えず、名前だけが出ます。オンにすると使えるようになります。ref や out の引数がある関数と、トリガーで扱えない型を使うものは、一覧に出ません。

呼ぶのは、このアクションが動いた画面のスクリプトです。その結果が全員に広がるかどうかは、相手のスクリプトしだいです。ProTV などの動画プレイヤーは、自分で全員の画面に同期します（[ほかのトリガーやスクリプト](/guide/linking)、[動画プレイヤー](/guide/video-players)）。
