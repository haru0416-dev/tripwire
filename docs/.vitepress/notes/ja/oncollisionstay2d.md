2D 物理のイベントで、ほかの Collider 2D と触れている間、続けて起きます。「触れている相手」は Collision2D という情報のまとまりです。Rigidbody が sleep 状態の間は、触れていても起きません（[2D の物体がぶつかったとき](/reference/events/oncollisionenter2d)）。

公式の説明: [OnCollisionStay2D（Unity）](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnCollisionStay2D.html)
