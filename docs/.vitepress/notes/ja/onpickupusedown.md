ピックアップを持った状態で Use ボタンを押したときに、自分の画面で起きます。銃を撃つ、ライトをつけるなど、持ったまま操作する仕掛けに向いています。

公式の説明では、デスクトップでこのイベントを使うには、VRC Pickup の Auto Hold がオンである必要があります。VR で試して動いても、デスクトップの人には起きないことがあるので気をつけてください。持っている間に出る案内は VRC Pickup の Use Text で決めます。Use Text も、Auto Hold がオンのときに出ます。

結果をほかの人にも見せたいときは、同期する変数を変えて「変数が変わったとき」で受けます。その場にいる人に音を聞かせるだけなら、詳細設定の「全員（All）」でも足ります（[全員で同じ状態にする](/guide/sync)）。

公式の説明: [Event Nodes（VRChat）](https://creators.vrchat.com/worlds/udon/graph/event-nodes/)、[VRC Pickup（VRChat）](https://creators.vrchat.com/worlds/components/vrc_pickup/)
