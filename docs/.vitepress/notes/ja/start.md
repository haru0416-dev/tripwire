各プレイヤーの画面で、そのオブジェクトが動き出したときに一度だけ起きます。ワールドに入ったプレイヤーの画面で起きるので、あとから来た人の画面でも起きます。

プレイヤーごとの初期設定（移動の速さを変える、など）に向いています。全員で共有したい最初の状態は、ここで作るより、同期する変数の「最初の値」で決めるほうが確実です。

Unity の説明では、Start はスクリプトが有効になったフレームで、最初の Update の直前に一度だけ呼ばれます。非表示で始まるオブジェクトでは、最初に表示されるまで起きません。

「最初から動かす」をオンにしたタイマーも、このときに動き始めます。各プレイヤーが入った時刻から数えるので、タイマーの進み方は人によってずれます（[タイマー](/reference/events/timer)）。

詳細設定を「全員（All）」にすると、誰かが入るたびに、その人の Start が全員の画面でアクションを動かします。ふつうは「自分だけ（Local）」のままにしてください。

Play 中の Inspector の「▶ 実行」では、このイベントは選べません。もう一度動かすと、タイマーの開始などが二重になるからです。

公式の説明: [Start（Unity）](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.Start.html)
