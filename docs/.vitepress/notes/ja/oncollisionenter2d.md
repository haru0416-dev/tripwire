2D 物理のイベントで、ほかの Collider 2D がこのオブジェクトの Collider 2D に当たったときに起きます。「ぶつかった相手」は Collision2D という情報のまとまりで、当たったときの情報が入っています。ふつうの 3D のコライダーやプレイヤーには使いません。

3D のぶつかり方については「[物体がぶつかったとき](/reference/events/oncollisionenter)」にあります。

公式の説明: [OnCollisionEnter2D（Unity）](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/MonoBehaviour.OnCollisionEnter2D.html)
