「呼ぶ名前」には、相手がトリガーならカードの「呼ばれる名前」を、UdonSharp のスクリプトなら public な関数の名前を書きます。対象をこのトリガー自身にして、その名前のカスタムイベントがないときは、Tripwire が注意を出します。

「誰の画面で」は、呼んだイベントをどこで動かすかの設定です。「自分だけ（Local）」なら、このアクションが動いた画面でその場ですぐに動きます。「全員（All）」はインスタンスにいる全員の画面で動き、送った本人の画面でも動きます。「オーナーだけ（Owner）」で動くのは、対象のオブジェクトのオーナーの画面だけです。

「全員（All）」と「オーナーだけ（Owner）」はネットワークで送るので、あとから来た人には届きません。あとから来た人にも見せたい状態は、同期する変数で持ってください（[全員で同じ状態にする](/guide/sync)）。ネットワークで送れる数には上限があり、超えた分は捨てられずに自分の側で順番を待ちます。

ネットワークで呼べるのは、名前が _ で始まらない public な関数だけです。_ で始まる名前をネットワークで送ろうとすると、Tripwire が注意を出します。
