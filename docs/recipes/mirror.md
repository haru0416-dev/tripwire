# 鏡の切り替え

クリックすると鏡が出たり消えたりするスイッチです。押した人の画面でだけ切り替わります。

## 用意するもの

- スイッチにするオブジェクト（コライダー付き）
- 鏡（VRChat SDK の VRCMirror など）

## カード

スイッチに Tripwire Trigger を付け、次のカードを作ります。

<TriggerCard event="Interact"
  :actions="[{ id: 'GameObject.ToggleActive', rows: [{ p: 0, value: 'Mirror', kind: 'object' }] }]" />

トリガーが空のときに出るひな形「クリックで表示を切り替える」を押すと、このカードができます。あとは「対象」に鏡を入れるだけです。

## 変えてみる

- 鏡を全員の画面で同時に切り替えたいときは、[全員で共有するスイッチ](./shared-switch) の形にします
- 鏡を 2 枚（高画質と軽量）切り替えたいときは、「対象」に 2 枚とも入れ、片方を最初から非表示にしておきます
